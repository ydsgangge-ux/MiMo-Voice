# 🎙️ MiMo 语音工坊

一个纯前端的小工具，基于小米 MiMo-V2.5-TTS 系列模型：**用文字描述生成全新音色并朗读**，或**上传几秒参考音频克隆音色**。单个 `index.html`，无需构建，可直接部署到 GitHub Pages，电脑和手机都能用。

🔗 **在线体验：<https://ydsgangge-ux.github.io/MiMo-Voice/>**

## 功能

- **文字生成语音**（`mimo-v2.5-tts-voicedesign`）：用一句话描述音色（年龄、性别、口音、气质、录音质感等），再输入要朗读的文本。页面内置了多种常用声线描述，点一下即可填入。
- **音色克隆**（`mimo-v2.5-tts-voiceclone`）：上传几秒参考音频（wav / mp3），无需训练，即可用该音色朗读新文本，还可以叠加风格指令（如“语气温柔缓慢”）。
- 生成后可在线试听，并下载 WAV 文件。
- 自适应电脑与手机屏幕，自动跟随系统深色 / 浅色模式。

## 使用方法

1. 到 [小米 MiMo 开放平台](https://platform.xiaomimimo.com/console/api-keys) 创建账号并生成 API Key。
2. 打开页面，把 Key 填入顶部的输入框。勾选“记住”后，Key 只会保存在你自己浏览器的本地存储里。
3. 选择“文字生成语音”或“音色克隆”，填写内容，点击生成。

## 部署到 GitHub Pages

1. 把 `index.html` 放进仓库（根目录或子目录均可）。
2. 打开仓库的 **Settings → Pages**，选择分支和目录，保存。
3. 等待几分钟，即可通过 Pages 地址访问。

## 隐私说明

- 本项目没有后端，API Key 和音频都不会经过任何第三方服务器。
- 请求直接从你的浏览器发送到 MiMo 官方接口。
- Key 默认只在当前页面使用，不会被写入仓库或页面源码。

## 常见问题

**提示“请求没有发出或被浏览器拦截”？**
可能是网络问题，或接口不允许浏览器跨域（CORS）访问。可在页面“高级”里把接口地址改成你自己的代理（代理只做转发，不要在代理里保存 Key）。

**生成的语音比我写的文本多出了几句？**
请确认页面里的 `optimize_text_preview` 选项保持关闭；同时避免在音色描述里写入像台词的句子，只描述声音特征。

**克隆别人的声音可以吗？**
请只克隆你本人或已获得授权的声音，并遵守 MiMo 平台的服务协议及当地法律法规。
